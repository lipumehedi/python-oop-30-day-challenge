# Day 23 – MRO & `super()`

## Overview

This folder contains practical Python OOP exercises for understanding Method Resolution Order (MRO), the `super()` function, and cooperative multiple inheritance.

## Topics Covered

* Method Resolution Order (MRO)
* `super()`
* Multiple Inheritance
* Cooperative Inheritance
* Method lookup
* Constructor chaining

## Exercises

| File            | Topic                               |
| --------------- | ----------------------------------- |
| `01_problem.py` | Basic `super()`                     |
| `02_problem.py` | MRO and Method Lookup               |
| `03_problem.py` | `super()` with Multiple Inheritance |
| `04_problem.py` | Cooperative Multiple Inheritance    |

## Learning Goals

* Understand how Python determines method lookup order.
* Practice using `super()`.
* Understand MRO in multiple inheritance.
* Chain parent constructors correctly.
* Learn the basic idea of cooperative multiple inheritance.

## Technologies

* Python 3
* Object-Oriented Programming (OOP)

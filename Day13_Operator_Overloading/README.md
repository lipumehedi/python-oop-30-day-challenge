# Day 13 – Operator Overloading

## Topics Covered

- Operator overloading
- __add__() for addition
- __sub__() for subtraction
- __mul__() for multiplication
- __eq__() for equality comparison

## Practice

### Problem 1 – Money Addition
Create a Money class and overload the + operator using __add__().

### Problem 2 – Point Subtraction
Create a Point class and overload the - operator using __sub__().

### Problem 3 – Product Multiplication
Create a Product class and overload the * operator using __mul__().

### Problem 4 – Student Comparison
Create a Student class and overload the == operator using __eq__().

## Goal

Understand how to customize operators for Python objects using special methods.

# Day 14 – Custom Exceptions & Exception Handling

## Topics Covered

- try and except
- raise
- finally
- Custom exception classes
- Exception handling in OOP

## Practice

### Problem 1 – Bank Withdrawal
Handle errors when a user tries to withdraw more money than the available balance.

### Problem 2 – Age Validation
Create a custom exception for invalid age.

### Problem 3 – Student Marks Validation
Raise an exception when marks are outside the valid range.

### Problem 4 – Login Validation
Create a custom exception for invalid login credentials.

## Goal

Understand how to handle errors and create custom exceptions in Python OOP.

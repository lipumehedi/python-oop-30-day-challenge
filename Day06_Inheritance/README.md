# Day 06 – Inheritance

## Topics Covered

- Inheritance
- Parent class
- Child class
- Reusing parent attributes and methods
- `super()`
- Method overriding

## Practice

### Problem 1
Create a parent class and a child class using inheritance.

### Problem 2
Use inherited attributes and methods.

### Problem 3
Use `super()` to initialize the parent class.

### Problem 4
Override a parent class method in the child class.

## Goal

Understand how inheritance allows a child class to reuse and extend the functionality of a parent class.

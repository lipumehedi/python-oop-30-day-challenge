# Day 27 – Unit Testing

## Overview

This folder contains practical Python exercises focused on Unit Testing using Python's built-in `unittest` framework.

The exercises demonstrate how to test classes, methods, expected results, and error conditions.

## Topics Covered

* `unittest`
* `TestCase`
* `assertEqual()`
* Unit Testing
* Class Testing
* Method Testing
* Test Success and Failure
* Exception Testing

## Exercises

| File            | Topic                    |
| --------------- | ------------------------ |
| `01_problem.py` | Basic Unit Testing       |
| `02_problem.py` | Testing Multiple Methods |
| `03_problem.py` | Testing Exceptions       |
| `04_problem.py` | Real-World Class Testing |

## Learning Goals

* Understand the purpose of Unit Testing.
* Learn how Python's `unittest` framework works.
* Create test cases using `TestCase`.
* Use assertions such as `assertEqual()`.
* Test Python classes and methods.
* Test expected exceptions.
* Build confidence in code reliability.

## Technologies

* Python 3
* Object-Oriented Programming (OOP)
* Unit Testing
* `unittest`

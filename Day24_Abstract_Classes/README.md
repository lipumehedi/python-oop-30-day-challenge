# Day 24 – Abstract Classes & Interfaces

## Overview

This folder contains practical Python OOP exercises focused on Abstract Classes, Abstract Methods, and Interfaces using Python's `abc` module.

## Topics Covered

* Abstract Classes
* Abstract Methods
* `ABC`
* `@abstractmethod`
* Interface concepts
* Method implementation in child classes
* Real-world OOP design

## Exercises

| File            | Topic                           |
| --------------- | ------------------------------- |
| `01_problem.py` | Basic Abstract Class            |
| `02_problem.py` | Multiple Abstract Methods       |
| `03_problem.py` | Abstract Class with Constructor |
| `04_problem.py` | Real-World Abstract Design      |

## Learning Goals

* Understand what an Abstract Class is.
* Understand how `ABC` works.
* Practice using `@abstractmethod`.
* Learn why child classes must implement abstract methods.
* Understand the basic concept of interfaces in Python.
* Apply abstraction to real-world problems.

## Technologies

* Python 3
* Object-Oriented Programming (OOP)

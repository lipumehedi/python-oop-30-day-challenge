# Day 21 – Descriptors

## Overview

This folder contains practical Python OOP exercises for learning Descriptors and controlling attribute access.

## Topics Covered

* Understanding Descriptors
* `__get__()`
* `__set__()`
* `__delete__()`
* Attribute access control
* Data Descriptors
* Validation using Descriptors

## Exercises

| File            | Topic                                |
| --------------- | ------------------------------------ |
| `01_problem.py` | Basic Descriptor                     |
| `02_problem.py` | Using `__get__()` and `__set__()`    |
| `03_problem.py` | Attribute Validation with Descriptor |
| `04_problem.py` | Using `__delete__()`                 |

## Learning Goals

* Understand what a Descriptor is.
* Learn how Python controls attribute access.
* Practice `__get__()`, `__set__()`, and `__delete__()`.
* Validate attribute values using Descriptors.
* Understand how Descriptors are related to Python's OOP system.

## Technologies

* Python 3
* Object-Oriented Programming (OOP)

# Day 29 – Library Management System

## Overview

This folder contains a practical Python OOP mini project focused on building a Library Management System.

The project simulates basic library operations such as managing books and members, borrowing books, returning books, validating operations, and handling exceptions.

## Features

* Create and manage books
* Create and manage library members
* Check book availability
* Borrow books
* Return books
* Track borrowed books
* Validate library operations
* Handle invalid operations with exceptions

## Topics Covered

* Classes and Objects
* Constructors
* Instance Attributes
* Instance Methods
* Encapsulation
* Object Relationships
* Lists
* Validation
* Exception Handling
* Book Management
* Member Management
* Borrow and Return Operations

## Learning Goals

* Build a real-world OOP project.
* Practice designing multiple related classes.
* Understand relationships between objects.
* Manage books and members using Python.
* Implement borrowing and returning operations.
* Validate library operations.
* Handle invalid operations safely.
* Combine multiple OOP concepts in one project.

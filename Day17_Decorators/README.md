# Day 17 – Decorators

## Topics Covered

* Decorators in Python
* Functions as arguments
* Nested functions
* `*args` and `**kwargs`
* `@decorator` syntax
* `functools.wraps()`

## Practice

### Problem 1 – Simple Decorator

Create a decorator that prints a message before and after a function runs.

### Problem 2 – Execution Timer

Create a decorator that measures the execution time of a function.

### Problem 3 – Login Decorator

Create a decorator that checks whether a user is logged in before allowing a function to run.

### Problem 4 – Uppercase Decorator

Create a decorator that converts a function's string result to uppercase.

## Goal

Understand how decorators work and how to use them to extend function behavior in Python.

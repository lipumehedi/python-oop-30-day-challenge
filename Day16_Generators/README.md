# Day 16 – Generators

## Topics Covered
- Generator functions
- yield
- next()
- Generator vs Iterator
- Generator expressions

## Practice

### Problem 1 – Number Generator
Create a generator that yields numbers from 1 to 5.

### Problem 2 – Countdown Generator
Create a generator that yields numbers from a starting value down to 1.

### Problem 3 – Even Number Generator
Create a generator that yields even numbers within a given range.

### Problem 4 – Name Generator
Create a generator that yields names one by one from a list.

## Goal
Understand how generators work and how `yield` can be used to create iterators easily.

# Day 28 – Bank Account System

## Overview

This folder contains a practical Python OOP mini project focused on building a Bank Account System.

The project combines Object-Oriented Programming, encapsulation, transactions, validation, and exception handling to simulate basic banking operations.

## Features

* Create a bank account
* Store account information
* Check account balance
* Deposit money
* Withdraw money
* Validate transaction amounts
* Handle insufficient balance
* Handle invalid transactions
* Use exception handling

## Topics Covered

* Classes and Objects
* Constructors
* Instance Attributes
* Instance Methods
* Encapsulation
* Validation
* Exception Handling
* Custom Exceptions
* Deposit and Withdrawal Operations
* Balance Management

## Project Structure

| File                       | Topic                              |
| -------------------------- | ---------------------------------- |
| `account.py`               | Account Class and Basic Operations |
| `deposit.py`               | Deposit Money                      |
| `withdraw.py`              | Withdraw Money                     |
| `exception_handling.py`    | Validation and Exception Handling  |

## Learning Goals

* Build a real-world OOP project.
* Practice designing classes and methods.
* Understand how banking transactions work in code.
* Validate user input.
* Handle invalid operations safely.
* Practice exception handling.
* Combine multiple Python OOP concepts in one project.

## Technologies

* Python 3
* Object-Oriented Programming (OOP)
* Exception Handling

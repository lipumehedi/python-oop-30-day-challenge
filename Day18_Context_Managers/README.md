# Day 18 – Context Managers

## Topics Covered

* Context Managers
* `with` statement
* `__enter__()` and `__exit__()`
* File handling with `with`
* Custom Context Managers
* `contextlib` module

## Practice

### Problem 1 – File Context Manager

Use the `with` statement to open and read a file safely.

### Problem 2 – File Writing Context Manager

Write text to a file using the `with` statement.

### Problem 3 – Custom Context Manager

Create a custom context manager using `__enter__()` and `__exit__()`.

### Problem 4 – Timer Context Manager

Create a context manager that measures the execution time of a code block.

## Goal

Understand how context managers manage resources and how to create custom context managers in Python.

# Day 20 – Property Decorators

## Overview

This folder contains practical Python exercises for learning Property Decorators and controlled attribute access.

## Topics Covered

* `@property`
* `@name.setter`
* `@name.deleter`
* Getter and Setter methods
* Attribute validation
* Encapsulation

## Exercises

| File            | Topic               |
| --------------- | ------------------- |
| `01_problem.py` | Basic `@property`   |
| `02_problem.py` | Using `@setter`     |
| `03_problem.py` | Property validation |
| `04_problem.py` | Using `@deleter`    |

## Learning Goals

* Access methods like attributes using `@property`.
* Update values using setters.
* Validate attribute values.
* Delete attributes using deleters.
* Understand controlled attribute access in Python.

## Technologies

* Python 3
* Object-Oriented Programming (OOP)

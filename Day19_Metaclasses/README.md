# Day 19 – Metaclasses

## Overview

This folder contains practical exercises for learning Python Metaclasses and class creation.

## Topics Covered

* Understanding `type()`
* Creating classes dynamically using `type()`
* Custom Metaclasses
* The `__new__()` method
* Validating class attributes

## Exercises

| File            | Topic                           |
| --------------- | ------------------------------- |
| `01_problem.py` | Understanding `type()`          |
| `02_problem.py` | Creating a class using `type()` |
| `03_problem.py` | Creating a custom metaclass     |
| `04_problem.py` | Validating class attributes     |

## Learning Goals

* Understand how Python creates classes.
* Learn the role of `type()` and metaclasses.
* Create custom metaclasses.
* Validate class attributes during class creation.

## Technologies

* Python 3
* Object-Oriented Programming (OOP)

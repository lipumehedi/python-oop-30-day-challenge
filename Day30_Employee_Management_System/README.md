# Day 30 – Employee Management System

## Overview

This is the final project of the Python OOP 30-Day Challenge.

The project combines multiple Python and Object-Oriented Programming concepts learned throughout the challenge to build a practical Employee Management System.

The system allows users to manage employee information, search employees, update salaries, delete employees, and save employee data to a JSON file.

## Features

* Create employee records
* Add employees
* Display all employees
* Search employees by Employee ID
* Update employee salary
* Delete employees
* Save employee data to JSON
* Validate employee operations
* Handle employee-not-found cases
* Unit testing

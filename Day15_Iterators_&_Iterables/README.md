# Day 15 – Iterators & Iterables

## Topics Covered

- Iterable vs Iterator
- __iter__()
- __next__()
- iter() and next()
- Custom iterator classes

## Practice

### Problem 1 – Number Iterator
Create a class that returns numbers one by one using an iterator.

### Problem 2 – Countdown Iterator
Create a countdown iterator that returns numbers from a starting value down to 1.

### Problem 3 – Name Iterator
Create a custom iterator that returns names one by one.

### Problem 4 – Even Number Iterator
Create a custom iterator that returns even numbers within a given range.

## Goal

Understand how to create and use custom iterators in Python OOP.

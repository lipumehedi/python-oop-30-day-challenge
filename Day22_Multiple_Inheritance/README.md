# Day 22 – Multiple Inheritance

## Overview

This folder contains practical Python OOP exercises for learning Multiple Inheritance and reusing functionality from multiple parent classes.

## Topics Covered

* Multiple Inheritance
* Multiple Parent Classes
* Method Reuse
* `super()`
* Constructor Inheritance
* Method Resolution Order (MRO) basics

## Exercises

| File            | Topic                               |
| --------------- | ----------------------------------- |
| `01_problem.py` | Basic Multiple Inheritance          |
| `02_problem.py` | Multiple Parent Methods             |
| `03_problem.py` | Multiple Inheritance with `super()` |
| `04_problem.py` | Constructor and Method Reuse        |

## Learning Goals

* Understand Multiple Inheritance.
* Inherit from more than one parent class.
* Reuse methods from multiple classes.
* Practice `super()`.
* Understand the basic idea of MRO.

## Technologies

* Python 3
* Object-Oriented Programming (OOP)

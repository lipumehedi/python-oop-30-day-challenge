# Day 25 – SOLID Principles

## Overview

This folder contains practical Python OOP exercises focused on the SOLID principles of software design. The exercises demonstrate how to write clean, maintainable, flexible, and reusable code.

## SOLID Principles Covered

* **S — Single Responsibility Principle (SRP)**
* **O — Open/Closed Principle (OCP)**
* **L — Liskov Substitution Principle (LSP)**
* **I — Interface Segregation Principle (ISP)**
* **D — Dependency Inversion Principle (DIP)**

## Exercises

| File            | Topic                           |
| --------------- | ------------------------------- |
| `01_problem.py` | Single Responsibility Principle |
| `02_problem.py` | Open/Closed Principle           |
| `03_problem.py` | Liskov Substitution Principle   |
| `04_problem.py` | Dependency Inversion Principle  |

## Learning Goals

* Understand the five SOLID principles.
* Learn how SOLID improves OOP design.
* Identify common design problems.
* Practice separating responsibilities.
* Build flexible and maintainable classes.
* Apply SOLID principles to real-world Python projects.

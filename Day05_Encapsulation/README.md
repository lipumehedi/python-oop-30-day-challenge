# Day 05 – Encapsulation

## Topics Covered

- Public attributes
- Protected attributes
- Private attributes
- Getter methods
- Setter methods
- Data protection
- Encapsulation in Python

## Practice

### Problem 1
Create an Employee class with a private salary attribute.

### Problem 2
Create getter and setter methods for a private attribute.

### Problem 3
Create a BankAccount class with a private balance.

### Problem 4
Create a BankAccount system using encapsulation for deposit and withdrawal.

## Goal

Understand how encapsulation protects data and controls how attributes are accessed and modified.


## Day 2 – Constructor & Instance Attributes

Practiced Python constructors and instance attributes using multiple real-world examples.

### Topics Covered

* `__init__()` constructor
* Instance attributes
* Creating multiple objects
* Accessing object attributes
* Updating instance attributes
* Understanding how each object maintains its own data

### Practice

* Student class
* Employee attribute update
* Multiple Employee objects
* BankAccount class with balance update

### Key Learning

Learned how to initialize object data using a constructor and update individual object attributes independently.
